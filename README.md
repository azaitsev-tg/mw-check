# Service Report — MyWellness NetCheck (`v1.0.0`)

Автономный браузерный инструмент для проверки DNS, TCP и SSL/TLS доступности облачных сервисов **Technogym MyWellness** из клиентской локальной сети или встроенного браузера консоли тренажёра (Live OS).

## Возможности

- Параллельная проверка 36 ключевых доменов (`*.mywellness.com`, `onedevice-api.technogym.com`, `amazonaws.com`, `googleapis.com` и др.) по протоколу HTTPS с таймаутом 5 секунд.
- Выполнение полностью на стороне клиента (`no-cors` fetch) без внешних зависимостей и серверного бэкенда.
- Формирование структурированного текстового отчёта с выводом проблемных узлов в начало лога, метаданными браузера и копированием в буфер обмена в один клик.

## Порядок использования на объекте

1. Отключить мобильную передачу данных (4G/5G) на смартфоне или открыть страницу напрямую в браузере консоли тренажёра.
2. Подключиться к Wi-Fi сети, через которую работают тренажёры.
3. Указать название клуба, нажать **«Запустить проверку (36)»** и после завершения нажать **«Скопировать лог»**.

## Версионирование

Проект придерживается [Semantic Versioning 2.0.0](https://semver.org/):
- `MAJOR` — изменение формата отчёта или механизма сетевых проверок;
- `MINOR` — добавление новых доменов или диагностических параметров;
- `PATCH` — правки вёрстки и исправления совместимости браузеров.
